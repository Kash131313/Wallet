# AckiNest – мульти‑кошелёк для сети Acki Nacki

**AckiNest** – это кроссплатформенное приложение (Windows, macOS, Linux, Android, iOS) написанное на **Rust + Tauri**. Оно позволяет хранить **множество** аккаунтов (seed‑фраз), переключаться между ними без выхода из кошелька и управлять **мультисиг‑кошельками**.

## Основные возможности

- **Мастер‑пароль** – единственная точка доступа к зашифрованному локальному хранилищу (`wallet_store.enc`).
- **Хранение seed‑фраз** в зашифрованном виде (AES‑256‑GCM + Argon2id). 
- **Добавление/удаление аккаунтов** и мгновенное переключение между ними.
- **Мультисиг‑кошельки** – указание участников, порог‑подписей, хранение данных в том же хранилище.
- **Автоблокировка** – приложение автоматически запрашивает пароль после периода бездействия.
- **UI** – простая веб‑страница в `dist/index.html` с темной темой, вкладками и toast‑уведомлениями.
- **Оффлайн‑режим** – без подключения к сети используется «заглушка», которая генерирует адрес из seed‑фразы (base64) и случайный баланс. Это позволяет разрабатывать и тестировать приложение без доступа к внешним сервисам.
- **Реальный режим** – при включении фичи `real` (см. ниже) используется официальная библиотека `tvm-sdk` и запросы к GraphQL‑endpoint `https://mainnet.ackinacki.org/graphql`.

│   │   ├─ crypto.rs       # шифрование/расшифровка, Argon2 + AES‑GCM

│   │   └─ network.rs       # сетевые вызовы (stub + real)

├─ dist/
│   └─ index.html           # UI‑страница (работает в браузере и в Tauri)

│   └─ src/lib.rs            # минимальная API‑поверхность (Mnemonic, KeyPair, Address)

## Как собрать и запустить

### 1. Предварительные требования

- **Rust** (stable) – `rustup toolchain install stable`
- **Node.js** (для сборки UI, если планируете React – не требуется сейчас, static HTML работает сразу)
- **Tauri CLI** (если хотите запускать в нативном окне):
  ```bash
  cargo install tauri-cli
  ```

### 2. Оффлайн‑сборка (по‑умолчанию)

Эта сборка использует **заглушку** `tvm-sdk` и не требует доступа к сети.

```bash
cd /Users/kash/Documents/claude_code/Wallet/acki_nest/src-tauri
# Убедитесь, что зависимость `tvm-sdk` указана как путь к ../.. (заглушка уже в репозитории)
cargo check            # проверка без сборки бинарника
cargo tauri dev        # запустить в режиме разработки (откроет окно Tauri)
```

Если хотите лишь посмотреть UI в браузере, откройте файл `dist/index.html` двойным‑кликом – весь код работает без Tauri.

### 3. Сборка с реальным SDK (опционально)

Если у вас есть доступ к интернету и вы хотите использовать настоящие функции Derive‑address и запрос баланса, выполните:

```bash
# 1️⃣ Скачайте реальный tvm‑sdk (пример, версия 0.3.0)
git clone https://github.com/tvmlabs/tvm-sdk.git /tmp/tvm-sdk
# 2️⃣ В Cargo.toml замените путь зависимости:
#    tvm-sdk = { path = "/tmp/tvm-sdk", optional = true }
# 3️⃣ Сборка с включенной фичей `real`
cargo build --features real
# 4️⃣ Запуск
cargo tauri dev
```

> **Важно:** реальная библиотека тянет множество зависимостей, сборка может занять несколько минут.

### 4. Тесты

Запуск тестов гарантирует, что криптография и хранение работают корректно:

```bash
cargo test                # запустит unit‑тесты, включая stub‑реализацию.
```

### 5. Сборка для дистрибутива

```bash
cargo tauri build          # получаете исполняемый файл в target/release/bundle/
```

## Фичи и переключения

В `Cargo.toml` объявлены две фичи:

- `default` – пустая, использует **заглушку**. Это вариант, который работает в любой среде без сети.
- `real` – включает реальные зависимости `tvm-sdk` и `reqwest`. Чтобы собрать с ней, укажите `--features real`.
