# CHANGELOG

## 2026‑08‑04 – v0.1.0 (initial public scaffold)
- Добавлен базовый Tauri‑проект со статическим UI.
- Реализовано шифрование мастер‑пароля (Argon2id + AES‑GCM).
- Хранилище `wallet_store.enc` с поддержкой обычных и мультисиг‑кошельков.
- UI со вкладками, автоблокировкой, toast‑уведомлениями.
- **Stub‑implementation** `tvm-sdk` (минимальная API‑поверхность) для офлайн‑сборки.
- Два варианта сборки через Cargo‑фичи: `default` (stub) и `real` (полный SDK, GraphQL‑запросы).
- Добавлен `mockInvoke` для демо‑режима в браузере.
- Интегрированы тесты `crypto` и `wallet_manager` (unit‑тесты).
- Обновлена документация (`README.md`, `PROJECT_STATE.md`).
